Song and video workflows in Umicom Media

The creative workspace contains two shared Framework pages:

  • Song and video plan: enter timed lyrics and a manual tempo, inspect shot boundaries, save/reopen a plan and export SRT captions.
  • PixVerse videos: use a locally saved API key to review a text-to-video request and explicitly check its job status.

Follow the song planning guide and PixVerse guide in the Applications checkout for the numbered workflows and recovery steps.

Save private plans outside the source repository. Song plans contain no audio; PixVerse results are not automatically downloaded, assembled or imported. These pages do not connect to Suno or SONDO. Local writing and timing need no provider account. PixVerse requires API access and credits.

The portable owners are available to other creative applications. Media composes the shared native pages; it does not keep a duplicate provider client or credential database.

Edit local video and add music

The Video sequence page adds local clip editing: add, trim, split, reorder, undo and redo, then save an editable JSON recipe at a location you choose. Preview uses the installed GTK media backend. Silent MP4 rendering uses a trusted FFmpeg executable selected by you.

After checking the silent render, expand Add soundtrack to a rendered video. Choose the video, an audio file and a fresh MP4 output path. The shared Framework renderer copies the video and attaches the selected sound, padding short audio with silence. This connects locally exported audio arrangements with video without a provider account.

See the video-sequence guide in the Applications checkout for the numbered workflow and recovery steps. The editor supports six clips and ten minutes, with sixteen undo steps. It does not provide multi-track video composition, transitions or automatic music generation. Renderer and playback support depend on installed tools; the applications do not download codecs or FFmpeg.

Add selectable captions

  1. Finish trimming and arranging the video. Render it, and add its soundtrack if needed.
  2. Use the captions editor to create or edit the words and cue timings, then export a UTF-8 SRT file. SRT, also called SubRip, stores a start time, end time and text for each caption.
  3. In Video sequence, open Add captions to a rendered video. Choose the finished video, the SRT file and a new output filename ending in .mp4.
  4. Check the trusted FFmpeg executable field and select Export with captions. Wait for the completion message. The operation uses the same Cancel button as rendering.
  5. Open the new file in a compatible video player and enable its subtitle track. Check the words, timing, full video length and sound before sharing it.

The export copies the first video stream and, when present, the first audio stream. Those streams must already use codecs supported in MP4. It adds one mov_text caption track and leaves out earlier subtitle tracks. FFmpeg must supply the SubRip decoder, mov_text encoder and MP4 writer.

Captions remain selectable; they are not permanently drawn into the picture. Timing is not adjusted automatically, and a cue past the end of the video can extend the container's reported duration. Keep cues within the intended video timeline. If a player does not show the captions, check its subtitle controls and format support.

The recipe, original video and SRT file are unchanged. An existing output filename is refused. A failed or cancelled export can leave a partial new file; choose another filename when retrying and read the renderer diagnostics. Caption paths are export inputs and are not saved inside the sequence recipe.
