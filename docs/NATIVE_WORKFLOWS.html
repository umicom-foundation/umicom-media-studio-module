Umicom Media user guide: edit and export a video sequence

A sequence is an ordered list of clips. Each clip refers to a source file and a time range. Editing the sequence changes a recipe; it does not overwrite the source video. This guide starts with a small local video and a new output filename.

Add and trim a clip

  1. Open Video Edit. The Media area holds source controls, the centre shows Preview, and the inspector holds clip settings.
  2. Enter a unique clip ID and a name. Use Browse beside the local video file field to choose a file you can read.
  3. Choose Add clip. Select the added clip in the sequence.
  4. Set its source start and end times in the inspector. These fields use milliseconds: 1,000 milliseconds is one second.
  5. Choose Apply trim. Confirm that the sequence reflects the new range.
  6. Use Undo, then Redo. The clip should return to its earlier and later ranges respectively.

Preview, split and move

  1. Select a clip and choose Preview selected clip. The current preview is silent.
  2. Choose Stop preview before changing to another source.
  3. Enter a valid split point inside the clip and choose Split clip. Inspect both resulting ranges.
  4. Use Move clip to change sequence order. Preview again to check the new order.

Preview support depends on the installed media backend and source format. An unsupported file should produce an error; it must not be counted as a successful preview.

Save the recipe and export

  1. Choose File → Project and recipe paths.
  2. Enter the title and output dimensions, then choose Apply settings.
  3. Choose a new recipe filename and use Save new recipe. A recipe stores editing instructions; it is not the rendered video.
  4. To reopen a recipe, select its path and review the permission to replace current edits before choosing Open recipe.
  5. Choose File → Export settings. Select the encoder program and a new output path you control.
  6. Choose the appropriate export: Render silent MP4, Export with soundtrack or Export with captions. Supply the additional inputs required by the latter two actions.
  7. Wait for the result and inspect the output file. Cancellation or an encoder error is not a completed export.

Export requires a compatible encoder installation. Saving and export use explicit paths. Existing output protection is intentional: choose a new filename rather than expecting an existing file to be replaced.

Menus and layout

Menu or controlPurpose
File: Project and recipe pathsShows the existing project controls.
File: Save new recipeRuns the same guarded save action as the editor toolbar.
File: Export settingsShows export configuration; it does not start a render.
Edit: Undo / Redo video editUses the editor’s history. Availability follows the underlying action.
View: Video editing / Asset library / Workspace layoutsChanges the visible tool without creating a second editing model.

Drag panel dividers to resize the source list, preview, inspector and sequence areas. Specialist modes expose different tools. An AI mode still needs a supported provider and a configured job; opening the page does not generate content.

Check a complete editing session

Add two clips, trim one, undo and redo, change tabs, save a new recipe and export to a new file. Check that the selected ranges survive navigation. Close and reopen the application, then explicitly open the saved recipe. Report any enabled control that silently does nothing, including its label and the preceding steps.
