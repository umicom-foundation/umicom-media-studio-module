Create avatar videos with HeyGen

The Avatar videos page connects to your HeyGen account to browse presenters and voices, create a synthetic character from a description, and turn a script into an avatar video. Framework owns the requests, local credentials and background work; Media supplies the creative workspace.

Save your key on this computer

  1. Open the Media creative workspace and select Avatar videos.
  2. Choose Manage local profile and API keys. Register the local default profile if you have not created it before. This page uses the umicom-media application scope.
  3. Save your HeyGen API key under the alias heygen. Use the key manager's explicit save action. The key lives in the supported operating-system credential store, not in a project or connection database.
  4. Return to Avatar videos. Enter that alias and your local profile password. This password unlocks the local key; it is not your HeyGen account password.

Use an avatar you already own

  1. Select Browse my private avatars or voices and choose Load avatars. Each action contacts HeyGen once and clears the password field afterward.
  2. Select a completed look and choose Use selected item. This fills Avatar look ID. Use Load next catalogue page to see more results; enter the local password again first. Turning off the private option browses the public catalogue instead.
  3. Enter the password again and choose Load voices. Select a voice, then choose Use selected item. Avatar and voice IDs remain separate.
  4. Enter a title, a script, and optional motion direction. Choose portrait output or subtitles if needed. Output requests use an MP4 container and a 1080p canvas.
  5. Enter the local password before choosing Review avatar video request. Read the exact request shown below the form. Approve that request and any HeyGen charge, then choose Send reviewed creation. Editing a field, including the password, invalidates the review.
  6. Copy the returned video ID somewhere private. Re-enter the local password and choose Check video status. Repeat only when you want another status request; there is no background polling.
  7. When the state is completed, the result shows a temporary private video URL and, if supplied by HeyGen, a subtitle URL. Copy the desired URL to your browser to download. These links may expire; checking status again obtains fresh links. No API key is attached by this page to a download link.

Create a character from a description

  1. Enter a character name and describe the synthetic presenter in the script/description box. Keep the description within 1000 UTF-8 bytes.
  2. Enter the local password, choose Review new character request, read the request, approve it, and send.
  3. Keep the returned avatar look ID. Choose Check avatar status after entering the password again. Wait for a completed state before using that ID with a script and voice.

Animate a short character scene

  1. Describe the scene and character action in the script box. This can be a short promotional shot rather than a speaking presenter.
  2. For a clip beginning from a character photo, supply its existing HeyGen image asset ID. The asset must already be uploaded to the same provider workspace. This page does not upload local files. Leave the ID empty to generate from text alone.
  3. Choose a duration from 5 to 15 seconds. Turn Portrait off when supplying an image: the image determines that clip's shape. Scene output uses 768p; avatar, voice, title, motion-direction and subtitle fields are not sent for scenes.
  4. Enter the password, choose Review short scene request, inspect the prompt and asset ID, approve the provider charge, then send. Prompt enhancement is disabled so the submitted direction is not automatically rewritten.
  5. Keep the returned video ID and use Check video status as above. Generation quality, credits and model access belong to HeyGen.

Recover from an interrupted request

Stop local request stops waiting on this computer; it does not cancel a render that HeyGen already accepted. A timeout or unreadable creation reply can mean a remote job exists even when its ID is unavailable locally. Check your HeyGen dashboard before preparing another creation, then use the acknowledgement checkbox. Reading a catalogue or checking another job does not clear this uncertainty. There is no automatic retry of a paid creation.

If access is denied, check the saved alias, local password, API-key permissions and the provider account. A busy response may mean a provider limit was reached. If HTTP transport is unavailable, the build needs its optional provider HTTP dependency. The key manager explains unsupported local credential storage instead of saving plaintext.

This page supports existing avatar looks and text-created synthetic presenters. It does not train digital twins from footage, upload photographs from this page, edit a video timeline, automatically download results, or persist a job history. Closing the page loses its displayed receipts; remote jobs remain in HeyGen. Provider permissions, credits and available avatars still apply. It is not a reproduction of every HeyGen feature.
